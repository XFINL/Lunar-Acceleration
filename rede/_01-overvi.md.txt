## 1. 项目定位

一个 **SaaS 化的 CDN 加速控制面板**，支持两种接入模式：

- **自建节点模式**：管理员部署 OpenResty 边缘节点，用户域名解析到平台，流量走自建节点（对标 GoEdge）
- **第三方厂商模式**：对接阿里云 / 腾讯云 / Cloudflare 等，面板做统一管理层（对标 Cloudflare 面板）

用户端呈现**统一的域名 / 缓存 / 回源 / HTTPS / 统计**界面，底层由「驱动层」屏蔽自建与厂商的差异。

**接入模式由用户所购套餐决定，用户无需手动选择。**

---

## 2. 核心特性

| 特性 | 说明 |
|------|------|
| 双接入模式 | 自建节点 + 第三方厂商，由套餐决定 |
| 多用户 SaaS | 万级用户，共享节点资源池 |
| RBAC 权限 | 超管 / 管理员 / 运维 / 用户 / 子用户 |
| 套餐计费 | 套餐包为主，流量为核心计量，支付占位 |
| 自建节点 | OpenResty，最多 500 节点，HTTP+Token 推送配置 |
| 调度中心 | CNAME + 第三方智能解析，负载均衡 + 故障转移 |
| WAF | CF 式自定义规则 + 默认规则库 |
| 网站配置 | 平台自身品牌 / 内容 / 支付 / 通知可后台配置 |
| 多语言 | 繁体中文（默认）/ en / jp / de |
| 一键部署 | Docker Compose |

## 3. 角色与权限

### 3.1 角色层级

| 角色 | 说明 |

- **动作维度**：create / read / update / delete / audit / deploy
- **数据范围**：all / group / self

## 4. 功能清单

### 4.1 用户端

**仪表盘**
- 实时流量 / 带宽 / 请求数 / 命中率卡片
- 套餐用量进度条、余额
- 域名状态概览、告警提醒

**域名管理**
- 添加域名（接入模式由套餐自动决定）
- CNAME 接入引导、DNS 检测
- 域名状态机：待审核 → 部署中 → 已启用 → 停用 → 已删除
- 批量操作、标签分组
- 域名详情页（Tab：概览 / 缓存 / 回源 / HTTPS / 访问控制 / WAF / 统计 / 日志）

**缓存配置**
- 缓存规则列表（优先级排序、拖拽）
- 匹配条件：路径 / 后缀 / 文件类型 / 状态码 / 请求头 / 参数
- 动作：TTL、忽略参数、强制缓存、不缓存、缓存键自定义
- 缓存刷新 / 预热：URL / 目录 / 标签刷新，任务队列与历史

**回源配置**
- 源站组管理（多源站、权重、主备）
- 回源协议（HTTP / HTTPS / 跟随）
- 回源 Host、回源端口
- 健康检查（探测路径、间隔、阈值）
- 回源超时、重试

**HTTPS / 证书**
- 上传证书、自动申请（ACME / Let's Encrypt）
- 证书绑定域名、到期提醒、自动续期
- 强制 HTTPS、HSTS、TLS 版本、加密套件

**访问控制**
- 防盗链（Referer 白名单 / 黑名单、签名 URL）
- IP 黑白名单、IP 段、地域封禁
- UA 限制
- 限速（QPS / 带宽 / 并发）

**WAF**
- 默认规则库（SQL 注入、XSS、命令注入、CC 防护等）
- 自定义规则：匹配条件（IP / 地区 / URL / Header / UA / Referer / Method / Body）
- 逻辑组合：AND / OR / NOT、正则
- 动作：放行 / 拦截 / 挑战 / 限速 / 记录日志
- 优先级、生效范围

**统计报表**
- 流量、带宽、请求数、命中率、状态码分布
- 地域分布、运营商分布、TOP URL / IP
- 时间维度：小时 / 天 / 周 / 月，自定义区间
- 导出 CSV / Excel

**日志**
- 访问日志查询（时间、域名、URL、状态码、IP、UA）
- 实时日志（WebSocket 推送，套餐可控，可选过滤）
- 日志下载、日志投递配置

**购买 / 计费**
- 套餐列表、购买、续费、升级
- 流量包 / 带宽包
- 账单明细、消费记录
- 充值（支付占位，先做接口预留）

**工单与公告**
- 提交工单、回复、附件
- 系统公告查看

**账户中心**
- 个人资料、修改密码、二次验证（2FA）
- API 密钥管理
- 子用户管理（可选）

### 6.1 数据流

**用户添加域名：**
1. 用户提交域名 → 后端校验 → 根据套餐决定接入模式
2. 自建模式：分配节点组 → 生成 CNAME → 推送配置到节点
3. 厂商模式：调用厂商 API 创建域名 → 同步配置
4. 用户按引导配置 CNAME → DNS 检测 → 域名启用

**用户请求：**
1. 用户访问 `cdn.example.com` → CNAME 解析到平台调度域名
2. 第三方智能解析根据访客 IP 返回最近节点
3. 节点 OpenResty 查本地缓存规则（Lua 读内存/Redis）
4. 命中则返回，未命中回源 → 缓存 → 返回

**配置变更：**
1. 用户/管理员修改配置 → 后端更新 DB
2. 后端计算 diff → 通过 HTTP+Token 推送到相关节点
3. 节点接收 → 写配置文件 → `reload` → 生效

**统计采集：**
1. 节点定时上报流量/请求数据 → 后端写入 `traffic_usage`
2. BullMQ 定时聚合 → 写入小时/天统计表
3. 前端查询聚合表展示

## 7. 规模与性能

| 项 | 目标 |
|----|------|
| 用户数 | 万级 |
| 域名数 | 1w+ |
| 节点数 | 最多 500 |
| 节点共享 | 共享资源池，不支持独享 |
| 统计粒度 | 小时 / 天 |
| 实时日志 | WebSocket，套餐可控 |

**性能要点：**
- 域名列表必须分页 + 搜索 + 筛选
- 缓存规则 / 回源配置单独表，不塞 JSON 主表
- 统计报表预聚合，不实时扫明细
- 刷新预热进队列，不同步阻塞
- 用户表预留分库分表能力
- 统计表按月分区
