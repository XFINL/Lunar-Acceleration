# CDN 加速控制面板 — API 设计

> 版本：v0.1
> 风格：RESTful
> 传输：HTTPS + JSON
> 认证：JWT（用户端/管理员端）+ Token（节点通信）
> 文档：Swagger 自动生成

---

## 1. 通用约定

### 1.1 基础路径

| 前缀 | 用途 | 认证 |
|------|------|------|
| `/api/v1/auth` | 认证 | 无 / JWT |
| `/api/v1/user` | 用户端 | JWT |
| `/api/v1/admin` | 管理员端 | JWT + RBAC |
| `/api/v1/node` | 节点通信 | Node Token |
| `/api/v1/webhook` | 回调 | 签名校验 |
| `/api/v1/openapi` | 对外API | AccessKey + SecretKey |

### 1.2 请求规范

**Header：**
```

Authorization: Bearer <jwt_token>
Content-Type: application/json
Accept-Language: zh-TW | en | jp | de
X-Request-Id: <uuid>          # 可选，链路追踪

```
**分页参数：**
```

?page=1&pageSize=20&sort=created_at&order=desc

```
**筛选参数：**
```

?keyword=xxx&status=1&startTime=2025-01-01&endTime=2025-01-31

```
### 1.3 响应格式

**成功：**
```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "requestId": "uuid"
}
```

分页：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [ ... ],
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 100,
      "totalPages": 5
    }
  },
  "requestId": "uuid"
}
```

错误：

```json
{
  "code": 40001,
  "message": "参数错误",
  "errors": [
    { "field": "domain", "message": "域名格式不正确" }
  ],
  "requestId": "uuid"
}
```

1.4 错误码规范

区间 含义
0 成功
40000-40099 参数错误
40100-40199 认证错误
40300-40399 权限错误
40400-40499 资源不存在
40900-40999 资源冲突
42900-42999 限流
50000-50099 服务器错误
60000-60099 业务错误
70000-70099 第三方错误

常用错误码：

code 说明
0 成功
40001 参数校验失败
40002 域名格式错误
40101 未登录
40102 Token 过期
40103 Token 无效
40301 无权限
40302 套餐不支持该功能
40303 配额已用完
40401 域名不存在
40402 节点不存在
40901 域名已存在
42901 请求过于频繁
50001 服务器内部错误
60001 域名审核中
60002 套餐已过期
70001 厂商API调用失败
70002 节点通信失败

1.5 时间格式

· 请求/响应统一 ISO 8601：2025-01-01T12:00:00Z
· 数据库存 UTC，展示层按用户时区转换

1.6 多语言

· Accept-Language 决定响应 message 语言
· 错误码固定，message 多语言映射
· 支持：zh-TW（默认）、en、jp、de

2. 权限模型（RBAC）

2.1 权限点命名

格式：<resource>:<action>

resource：

```
domain, cache, origin, cert, purge, waf, statistics, log,
node, vendor, schedule, user, package, order, ticket,
notice, site_config, system_config, audit, report
```

action：

```
create, read, update, delete, audit, deploy, export
```

2.2 权限点清单

域名

```
domain:create  domain:read  domain:update  domain:delete  domain:audit
```

缓存

```
cache:create  cache:read  cache:update  cache:delete
```

回源

```
origin:create  origin:read  origin:update  origin:delete
```

证书

```
cert:create  cert:read  cert:update  cert:delete
```

刷新预热

```

```

```
waf:create  waf:read  waf:update  waf:delete
```

统计

```

```

日志

```

```

节点

```
node:create  node:read  node:update  node:delete  node:deploy
```

厂商

```
vendor:create  vendor:read  vendor:update  vendor:delete
```

调度

```
schedule:create  schedule:read  schedule:update  schedule:delete
```

用户

```
user:create  user:read  user:update  user:delete
```

套餐

```

```

```

```

```

```

```

```

```

审计

```

```

报表

```
report:read  report:export
```

2.3 角色默认权限

角色 权限
超级管理员 全部
管理员 除 node:deploy、system_config:update、vendor:delete 外全部
运维 node:、vendor:read、schedule:、statistics:read、log:read
用户 自己资源的所有权限（domain/cache/origin/cert/purge/waf/statistics/log 的 CRUD）
子用户 由主用户分配

2.4 数据范围

· all：全部数据（超管、管理员）
· group：本组数据（运维看自己负责的节点组）
· self：自己的数据（用户只看自己的域名）

6. 节点通信接口

Header: X-Node-Id: 1
        X-Node-Token: xxxxxx
        X-Timestamp: 1704067200
        X-Signature: hmac_sha256(body + timestamp, token)

Body:
{
  "nodeId": 1,
  "version": "1.21.4.1",
  "uptime": 86400,
  "load": { "cpu": 12.5, "mem": 45.2, "disk": 30.1 },

  "qps": 567
}

  ]
}
```

上报流量：

6.2 控制端 → 节点

推送配置：

```
POST https://<node-ip>:443/config/push
Header: X-Node-Token: xxxxxx
        X-Timestamp: 1704067200
        X-Signature: hmac_sha256(body + timestamp, token)

Body:
{
  "version": 123,
  "type": "full" | "incremental",
  "configs": {
    "domains": [ ... ],
    "cacheRules": [ ... ],
    "origins": [ ... ],
    "certs": [ ... ],
    "wafRules": [ ... ]
  }
}
```

触发重载：

```
POST https://<node-ip>:443/config/reload
Header: X-Node-Token: xxxxxx
Body: { "version": 123 }
```

下发指令：

```
POST https://<node-ip>:443/command
Header: X-Node-Token: xxxxxx
Body:
{
  "command": "purge" | "upgrade" | "restart",
  "params": { "urls": ["..."] }
}
```

6.3 签名规则

```
signature = HMAC-SHA256(
  body_json_string + "|" + timestamp,
  node_token
)
```

· timestamp 为 Unix 秒，与服务器时间偏差不超过 300 秒
· 防重放：控制端缓存最近 5 分钟的 signature

8. 对外 OpenAPI

独立鉴权：AccessKey + SecretKey
签名：HMAC-SHA256

8.1 签名规则

```
stringToSign = HTTPMethod + "\n" +
               Path + "\n" +
               QueryString + "\n" +
               AccessKey + "\n" +
               Timestamp + "\n" +
               BodyMD5

signature = Base64(HMAC-SHA256(stringToSign, SecretKey))
```

Header：

```
X-Access-Key: xxx
X-Timestamp: 1704067200
X-Signature: xxx
```

8.2 开放接口

```
POST   /api/v1/openapi/domain/create      添加域名

```bash
curl -X POST https://panel/api/v1/admin/nodes \
  -H "Authorization: Bearer eyJ..." \
  -H "Content-Type: application/json" \
  -d '{
    "name": "香港节点-01",
    "ip": "1.1.1.1",
    "port": 443,
    "region": "HK",
    "nodeGroupId": 1
  }'

10.3 节点上报心跳

```bash
TIMESTAMP=$(date +%s)
BODY='{"nodeId":1,"version":"1.21.4.1","load":{"cpu":12.5}}'
SIGNATURE=$(echo -n "${BODY}|${TIMESTAMP}" | openssl dgst -sha256 -hmac "node_token" | awk '{print $2}')

curl -X POST https://panel/api/v1/node/heartbeat \
  -H "X-Node-Id: 1" \
  -H "X-Node-Token: node_token" \
  -H "X-Timestamp: ${TIMESTAMP}" \
  -H "X-Signature: ${SIGNATURE}" \
  -H "Content-Type: application/json" \
  -d "${BODY}"
```
