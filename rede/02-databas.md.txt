# CDN 加速控制面板 — 数据库设计

> 版本：v0.1
> 数据库：MySQL 8.0
> 字符集：utf8mb4 / utf8mb4_unicode_ci
> 引擎：InnoDB
> 时区：UTC 存储，展示层转换

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 主键 | 统一 `bigint unsigned auto_increment`，避免 UUID 索引膨胀 |
| 软删除 | 重要表用 `deleted_at`，不物理删除 |
| 时间字段 | `created_at` / `updated_at` 统一 datetime |
| 金额 | `decimal(12,2)`，不用 float |
| 流量 | `bigint`，单位字节 |
| 带宽 | `int`，单位 Kbps |
| JSON | MySQL 原生 JSON 类型，用于弹性配置 |
| 枚举 | `tinyint` + 代码注释，不用 ENUM 类型 |
| 索引 | 高频查询字段建索引，联合索引遵循最左前缀 |
| 分区 | 大表按月分区（统计、日志、审计） |
| 分片 | 用户表预留按 user_id 哈希分片能力 |

---

|------|----|

| 调度中心 | schedule_policies, dns_records, loadbalance_rules, failover_rules |
| 统计 | traffic_stats_hourly, traffic_stats_daily, region_stats, status_code_stats, top_url_stats |

| 系统配置 | system_configs, alarm_rules, alarms |

## 3. 用户与权限模块

### 3.1 users 用户表

```sql
CREATE TABLE `users` (
  `id`              bigint unsigned NOT NULL AUTO_INCREMENT,
  `username`        varchar(64)     NOT NULL COMMENT '用户名',
  `email`           varchar(128)    DEFAULT NULL COMMENT '邮箱',
  `phone`           varchar(32)     DEFAULT NULL COMMENT '手机号',
  `password_hash`   varchar(255)    NOT NULL COMMENT '密码哈希',
  `nickname`        varchar(64)     DEFAULT NULL COMMENT '昵称',
  `avatar`          varchar(255)    DEFAULT NULL COMMENT '头像URL',
  `status`          tinyint         NOT NULL DEFAULT 1 COMMENT '0禁用 1正常 2待审核',
  `role_type`       tinyint         NOT NULL DEFAULT 1 COMMENT '1用户 2管理员 3超管',
  `balance`         decimal(12,2)   NOT NULL DEFAULT 0.00 COMMENT '余额',
  `package_id`      bigint unsigned DEFAULT NULL COMMENT '当前套餐ID',
  `package_expire_at` datetime      DEFAULT NULL COMMENT '套餐到期时间',
  `invite_code`     varchar(32)     DEFAULT NULL COMMENT '邀请码',
  `inviter_id`      bigint unsigned DEFAULT NULL COMMENT '邀请人ID',
  `two_fa_secret`   varchar(64)     DEFAULT NULL COMMENT '2FA密钥',
  `last_login_at`   datetime        DEFAULT NULL,
  `last_login_ip`   varchar(64)     DEFAULT NULL,
  `created_at`      datetime        NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at`      datetime        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `deleted_at`      datetime        DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`),
  UNIQUE KEY `uk_email` (`email`),
  UNIQUE KEY `uk_invite_code` (`invite_code`),
  KEY `idx_status` (`status`),
  KEY `idx_package_id` (`package_id`),
  KEY `idx_created_at` (`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

16. 索引与分区策略

16.1 索引原则

场景 策略
高频查询 建联合索引，遵循最左前缀
分页 用 id 或 created_at 做游标
模糊搜索 前缀匹配走索引，%xxx% 不走
排序 排序字段入索引
唯一约束 业务唯一字段建唯一索引

16.2 分区表清单

表 分区键 粒度
user_login_logs created_at 月
traffic_usage stat_time 月
node_metrics stat_time 月
traffic_stats_hourly stat_time 月
waf_logs created_at 月
audit_logs created_at 月

分区维护：

· 用定时任务每月自动创建下月分区
· 过期分区归档或删除（按保留策略）

16.3 分片预留

users 表预留按 user_id 哈希分片能力：

· 万级用户单表够用
· 超过 100w 时按 user_id % N 分片
· 关联表（domains、orders 等）同步分片
