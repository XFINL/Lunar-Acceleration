# CDN 加速控制面板 — 前端设计

> 版本：v0.1
> 框架：React 18 + TypeScript
> 构建：Vite
> UI：shadcn/ui + Tailwind CSS
> 图表：Recharts

---

## 1. 技术选型

### 1.1 核心依赖

| 类别 | 选型 | 说明 |
|------|------|------|
| 框架 | React 18 | 并发特性、Suspense |
| 语言 | TypeScript 5 | 严格模式 |
| 构建 | Vite 5 | 快速 HMR |
| 路由 | React Router v6 | 嵌套路由、懒加载 |
| 状态 | Zustand | 轻量全局状态 |
| 数据请求 | TanStack Query v5 | 缓存、重试、轮询 |
| 表单 | React Hook Form | 性能好 |
| 校验 | Zod | 与 RHF 集成 |
| UI 库 | shadcn/ui | 可复制组件，非 npm 包 |
| 样式 | Tailwind CSS 3 | 原子化 |
| 图标 | Lucide React | shadcn 默认图标 |
| 图表 | Recharts | 声明式 |
| 表格 | TanStack Table v8 | 无头表格 |
| 国际化 | i18next + react-i18next | 多语言 |
| 实时 | Socket.IO Client | WebSocket |
| 日期 | date-fns | 轻量 |
| 工具 | lodash-es | 按需引入 |
| 通知 | sonner | Toast |
| 代码规范 | ESLint + Prettier | |

### 1.2 开发依赖

| 类别 | 选型 |
|------|------|
| 包管理 | pnpm |
| Monorepo | pnpm workspace |
| 类型检查 | tsc |
| Git Hook | husky + lint-staged |
| 提交规范 | commitlint |
| 测试 | Vitest + Testing Library |
| E2E | Playwright（可选） |

5. API 客户端

5.1 Axios 实例

```ts
// api/client.ts
const client = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json',
  },
})

// 请求拦截：注入 Token、语言
client.interceptors.request.use((config) => {
  const token = useAuthStore.getState().accessToken
  if (token) config.headers.Authorization = `Bearer ${token}`
  config.headers['Accept-Language'] = useLocaleStore.getState().locale
  return config
})

// 响应拦截：统一处理 code、错误
client.interceptors.response.use(
  (res) => {
    if (res.data.code !== 0) {
      toast.error(res.data.message)
      return Promise.reject(res.data)
    }
    return res.data
  },
  async (error) => {
    // 401 → 刷新 Token → 重试
    // 403 → 提示无权限
    // 429 → 提示限流
    // 5xx → 提示服务器错误
  }
)
```

5.2 Token 刷新

· 401 时用 refreshToken 换新 accessToken
· 并发请求排队，只刷新一次
· 刷新失败 → 登出 → 跳登录页

5.3 文件上传

```ts
export async function uploadFile(file: File, type: string) {
  const formData = new FormData()
  formData.append('file', file)
  formData.append('type', type)
  return client.post('/api/v1/upload', formData, {
    headers: { 'Content-Type': 'multipart/form-data' },
  })
}
```

5.4 下载

```ts
export async function downloadFile(url: string, filename: string) {
  const res = await client.get(url, { responseType: 'blob' })
  const blob = new Blob([res.data])
  const link = document.createElement('a')
  link.href = URL.createObjectURL(blob)
  link.download = filename
  link.click()
}
```
